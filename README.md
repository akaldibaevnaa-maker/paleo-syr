# Сыр өңірінің палеонтологиялық шежіресі 🦖

Бұл жоба республикалық ғылыми жобалар байқауына дайындалған интерактивті палеонтологиялық платформа болып табылады.
Сайт HTML5, CSS3 (Tailwind CSS) және Vanilla JavaScript арқылы жазылған. Қосымша серверлік логиканы немесе дерекқорды қажет етпейді, сондықтан оны **GitHub Pages** арқылы өте оңай интернетке орналастыруға болады.

## Файлдар құрылымы
- `index.html` — Платформаның негізгі және жалғыз коды. Мұнда барлық разметка, стильдер (Tailwind арқылы) және интерактивті логика (Викторина, Карта, Геологиялық қабаттар) біріктірілген.

## GitHub Pages арқылы қалай іске қосуға болады? (Нұсқаулық)

1. **GitHub аккаунты:**
   Егер сізде [GitHub](https://github.com/) аккаунты жоқ болса, тіркеліңіз.

2. **Жаңа репозиторий құру:**
   - Оң жақ жоғарғы бұрыштағы `+` белгісін басып, **New repository** таңдаңыз.
   - Репозиторий атауын жазыңыз (мысалы: `paleo-syr`).
   - "Public" (ашық) түрін таңдап, **Create repository** батырмасын басыңыз.

3. **Файлды жүктеу:**
   - Жаңа ғана ашылған репозиторий бетінде **"uploading an existing file"** (бар файлды жүктеу) сілтемесін басыңыз.
   - Осы папкадағы `index.html` файлын сүйреп әкеліп тастаңыз немесе таңдап жүктеңіз.
   - Төмендегі **Commit changes** батырмасын басып, сақтаңыз.

4. **GitHub Pages қосу:**
   - Репозиторийдің жоғарғы мәзірінен **Settings** (Баптаулар) бөліміне өтіңіз.
   - Сол жақ мәзірден **Pages** бөлімін таңдаңыз.
   - **Source** (Дереккөз) бөліміндегі "None" дегенді **"main"** (немесе "master") етіп өзгертіңіз және **Save** (Сақтау) батырмасын басыңыз.

5. **Дайын!**
   - Бірнеше минуттан кейін жоғарыда сіздің сайтыңыздың сілтемесі пайда болады (мысалы: `https://[сіздің-логиніңіз].github.io/paleo-syr/`). 
   - Осы сілтемені ғылыми жоба қорғау кезінде комиссияға көрсетуге немесе презентацияға қосуға болады.

Сәттілік тілеймін! 🚀
